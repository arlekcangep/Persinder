# Persinder

**Персональный индексатор** — поисковый движок для персональной базы знаний.

## Описание

Persinder индексирует информацию из различных источников:

- **Obsidian** — заметки и связи между ними
- **Local files** — PDF, DOCX, изображения, DjVu, ZIP-архивы
- **Web** — веб-страницы и онлайн-материалы

## Возможности поиска

- **Поиск по совпадению слов** — классический полнотекстовый поиск
- **Поиск по тэгам** — фильтрация и навигация по меткам
- **Семантический поиск** — поиск по смыслу, а не только по точным словам

## Авто-каталогизирование

Persinder ведёт автоматическое каталогизирование:

- закладок
- книг
- статей
- CD-архивов

## Платформы

## Разработка

Ядро — на стандартной библиотеке Python; единственная обязательная внешняя
зависимость — `onnxruntime` (+ `tokenizers`): у него официальные колеса для
Windows/Linux/macOS, поэтому Persinder ставится и работает «из коробки», без
Docker. Сама модель эмбеддингов (~120 МБ) — не в пакете, а управляется явно:
`persinder model install`.

```bash
# тесты
PYTHONPATH=src python3 -m unittest discover -s tests

# запуск сервиса приёма (модуль 1)
PYTHONPATH=src python3 -m persinder --data-dir ~/.persinder --port 8756

# эмбеддинги по требованию: очередь → векторы → сайдкары (модуль 2)
PYTHONPATH=src python3 -m persinder embed --data-dir ~/.persinder

# модель эмбеддингов: установка и переключение (D24)
PYTHONPATH=src python3 -m persinder model install e5-small-int8-v1   # веса + миграция в очередь
PYTHONPATH=src python3 -m persinder embed --background               # разобрать очередь до пустой
PYTHONPATH=src python3 -m persinder model use e5-small-int8-v1       # переключить поиск

# семантический поиск (модуль 3): морфология + семантика
PYTHONPATH=src python3 -m persinder search "коты сидят" --limit 10

# ANN-индекс USearch: пересобрать из таблицы (холодный старт/рассинхрон)
PYTHONPATH=src python3 -m persinder ann rebuild

# проверка
curl -s localhost:8756/health
curl -s -X POST localhost:8756/ingest \
  -H 'Content-Type: application/json' \
  -d '{"filename":"note.md","area":"personal","text":"Привет мир"}'
```

Реализованы **модуль 1** (`ingest` — приём текста, морфологический слой FTS5,
журнал вызовов, инлайн-удаление), **модуль 2** (`embed` — воркер очереди:
текст → векторы → сайдкары, реестр моделей и явный модель-менеджмент) и
**модуль 3** (`vectorindex` — семантический поиск: ANN USearch `data_dir/ann/`
поверх таблицы `embeddings`, точный скан таблицы как фолбэк).
Эмбеддер — реальная модель e5-small (ONNX INT8, `persinder model install`)
или детерминированная заглушка (`placeholder-v1`, встроена). У файла живут
сайдкары нескольких моделей сразу (по подпапке на модель): при установке новой
модели миграция стартует в фоне, поиск остаётся на старой до явного
`persinder model use`; удаление `persinder model remove` убирает веса, все
сайдкары и векторы модели в один момент. Векторный поиск идёт активной
поисковой моделью (`model use`), в ответе `/search` семантические хиты —
отдельным полем `semantic_hits` рядом с `hits`. Векторный поиск идёт по
USearch-индексу (mmap-файл на модель, `persinder ann rebuild` пересобирает);
единое ранжирование (D16) — следующий шаг. Карта и интерфейсы — в
`docs/modules.md`.
